Telescope Simulator

A physics-based telescope simulator: ray tracing, diffraction, atmospheric seeing and simulated eyepiece views.

The browser version

The simulator page runs the desktop application itself (the same Python code) in your browser through Pyodide, which is Python compiled to WebAssembly. Everything runs on your computer and nothing is sent to a server.

It differs from the desktop app in a few small ways:

  • Plots are static images with no zoom or pan toolbar.
  • There is no menu bar.
  • The page cannot redraw while a simulation is computing, so it shows "Working…".

Download the desktop app

The desktop app is the same simulator in a native window. Use it to work offline, or to check the browser version.

Download source, v1.0 (zip, 1.6 MB)

It needs Python 3.11 or newer. Unzip it, open a terminal in the folder, then run:

python3 -m venv venv
source venv/bin/activate            # Windows: venv\Scripts\activate
pip install -r requirements.txt
python gui.py

INSTALL.md in the zip has the full instructions, including how to run the test suite.
